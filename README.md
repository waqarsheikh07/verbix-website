# Verbix website

Static multi-page site for Verbix academic editing, served with GitHub Pages.

- Pages: `index.html`, `services.html`, `pricing.html`, `about.html`, `faq.html`, `integrity.html`, `contact.html`, `404.html`
- Styles: `assets/css/site.css`
- All page HTML is generated by `tools/build_site.py`. Edit copy, prices, the WhatsApp number (`WA`) or photos (`IMG`) there, then run `python3 tools/build_site.py`.
